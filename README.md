# Opis projektu
Analiza danych interfejsu API ligi fantasy football z użyciem notatników Jupyter, potoku danych (Apache Airflow) oraz aplikacji do wizualizacji danych (biblioteka Streamlit).

# Słowa klucze projektu
Python, Pandas, interfejsy API, kody stanu, Jupyter, potok danych, Apache Airflow, wizualizacja danych, Streamlit

# Źródło projektu
Day Ryan, Interfejsy API w AI i Data Science: programowanie w Pythonie z użyciem FastAPI, 2025, Helion
